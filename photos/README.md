# Dossier photos

Placez ici les photos des navires, nommées par armateur :

- `cma-cgm.jpg`
- `msc.jpg`
- `maersk.jpg`
- `hapag-lloyd.jpg`
- `one.jpg`
- `evergreen.jpg`

La fiche d'un navire affiche la photo correspondante si le fichier existe,
sinon une illustration générée automatiquement prend le relais.

⚠️ Ne pas committer ici de photos protégées par le droit d'auteur si le dépôt
est public : elles seraient rediffusées publiquement. Utilisez-les en local,
ou remplacez-les par des images libres de droits.
