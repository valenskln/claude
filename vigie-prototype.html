VIGIE — prototype de faisabilité

Croiser le tracking des porte-conteneurs avec l’analyse du risque géopolitique.

Ce qui est réel dans ce prototype

  • Les 8 zones à risque, leurs scores et le contexte : basés sur la situation géopolitique réelle (zones listées par le Joint War Committee, attaques en mer Rouge, guerre en mer Noire, piraterie dans le golfe de Guinée…).
  • Les routes maritimes : corridors réels du commerce conteneurisé, y compris le déroutement par le cap de Bonne-Espérance.
  • Les armateurs : les 9 premiers opérateurs mondiaux.
  • Le moteur d’alerte : détection de proximité et d’entrée en zone, classement d’exposition — c’est la vraie logique du produit final.

Ce qui est simulé

  • Les positions des navires : flotte fictive animée le long des corridors. En production, elles viendraient d’un flux AIS temps réel (aisstream.io, Spire Maritime, MarineTraffic…).
  • Le temps est accéléré (réglable en haut à droite) pour rendre les mouvements visibles.

Le temps réel est intégré 🛰️

  • Clique sur « AIS direct » dans l'en-tête et colle ta clé gratuite aisstream.io : les vrais navires remplacent la simulation, et tout le moteur (heatmap, alertes, classement) s'applique à leurs positions réelles.
  • ⚠️ Fonctionne en ouvrant le fichier sur ton ordinateur — l'aperçu Claude bloque les connexions externes par sécurité.

Prochaines étapes

  • Scoring dynamique : alimenter les scores avec GDELT / ACLED / UKMTO / IMB au lieu de valeurs fixées à la main.
  • Backend : stockage des trajectoires, calculs de proximité côté serveur, notifications push / e-mail, comptes utilisateurs.

Astuce : cliquez sur un navire ou une zone sur la carte, ou dans les classements. Molette pour zoomer, cliquer-glisser pour déplacer.

2. Menu « API Keys » → génère une clé
