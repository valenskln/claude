AIS DIRECT

Remplace la flotte simulée par les vraies positions des navires, via aisstream.io (gratuit).

  1. Crée un compte sur aisstream.io (connexion GitHub).
  2. Menu « API Keys » → génère une clé.
  3. Colle-la ici.
Couverture : antennes côtières (≈ 40 à 60 milles des côtes) — la haute mer a des trous, c'est normal. Une seule connexion par clé : ferme les autres onglets Proteus. Ta clé reste dans ce navigateur, elle n'est envoyée qu'à aisstream.io. Dans un aperçu en ligne, les connexions externes peuvent être bloquées : ouvre le fichier sur ton ordinateur. En mode direct, le recoupement satellite est coupé (pas de source satellite branchée) : rien n'est inventé sur des navires réels.
